安装说明

蓝灵提供 Windows 在线安装版。安装器会在你的用户目录下配置一套完全独立的 Python 运行环境与光学计算引擎，然后自动完成部署，全程不改动系统 Python，也不需要管理员权限。

Windows 10 / 11 64 位 安装过程需要联网 无需管理员权限 独立 Python 3.13.12 Optiland 0.6.1 光学引擎

1下载与校验

从官网或 Release 页面下载在线安装包。安装包本身只包含蓝灵程序、界面资源与镜头库，因此体积很小。

安装包信息

文件名BlueSpirit-Setup.exe
文件大小1,897,414 字节（1.81 MiB）
适用系统Windows 10 / 11 64 位
安装权限当前用户，无需管理员权限
下载直链https://github.com/Alice-P197/BlueSpirit/releases/latest/download/BlueSpirit-Setup.exe
SHA256 23B56F8C138C54844E5D4641DC148AC2E346B6971AE2D641FADC13757B2D9791

下载后可在 PowerShell 中校验文件是否完整：

# 校验安装包完整性
Get-FileHash -Algorithm SHA256 .\BlueSpirit-Setup.exe

输出的哈希值应与上方的 SHA256 完全一致。若不一致，说明下载未完成或文件被替换，请重新下载。

2执行安装

双击 BlueSpirit-Setup.exe 启动安装向导，按提示完成即可。

向导步骤

  1. 欢迎页：确认安装器版本，点击下一步。
  2. 选择安装目录：默认为 %LOCALAPPDATA%\BlueSpirit，可直接使用或改为其他目录。
  3. 安装过程：安装器会依次完成程序文件释放、独立 Python 运行时配置、pip 准备，以及 PySide6、Optiland 0.6.1 与科学计算依赖的安装。这一步需要联网，耗时取决于网络状况。
  4. 完成页：可勾选立即启动蓝灵，桌面与开始菜单会同时创建快捷方式。
安装器依赖下载具备自动重试与镜像回退：包索引优先使用清华镜像，失败后回退 PyPI；Python 运行时来自 python.org，失败后回退华为云镜像。安装结束前会执行完整运行库校验，只有在所有必需模块与依赖一致性检查通过后才会判定为安装成功。

静默安装（可选）

在需要批量部署或脚本化安装时，可以使用 NSIS 静默参数，并指定安装目录：

BlueSpirit-Setup.exe /S /D=C:\BlueSpirit

/S 表示静默安装，/D= 后紧跟目标目录且不带引号。目录必须以当前用户可写的路径开头。

3首次启动

安装完成后可通过三种方式启动蓝灵：

  • 桌面上的「蓝灵 BlueSpirit」快捷方式。
  • 开始菜单 BlueSpirit 分组中的「蓝灵 BlueSpirit」。
  • 直接运行 %LOCALAPPDATA%\BlueSpirit\BlueSpirit\runtime\python\pythonw.exe "%LOCALAPPDATA%\BlueSpirit\BlueSpirit\main.py"。
首次启动会创建数据目录、镜头库索引与默认工作区，镜头库共 1,488 条定义会在打开镜头库时全部载入，其中已验证可用的条目直接恢复缓存，其余条目按需实例化。

4目录与数据

蓝灵的程序文件、运行环境与用户数据分开放置，卸载程序不会影响用户数据。

安装目录（默认）

路径内容
%LOCALAPPDATA%\BlueSpirit\BlueSpirit\main.py程序入口
%LOCALAPPDATA%\BlueSpirit\BlueSpirit\app\界面、核心模块、光场调控与光学计算资源
%LOCALAPPDATA%\BlueSpirit\BlueSpirit\resources\镜头资源与设计模板
%LOCALAPPDATA%\BlueSpirit\BlueSpirit\runtime\python\独立 Python 3.13.12 运行环境（不占用系统 Python）
%LOCALAPPDATA%\BlueSpirit\Setup\install.log安装日志
%LOCALAPPDATA%\BlueSpirit\Uninstall.exe卸载程序

安装完成后整体占用约 1.5 GiB，其中绝大多数来自 Qt 与科学计算依赖的独立运行环境。

用户数据目录

路径内容
%APPDATA%\BlueSpirit\会话记录、报告、镜头库版本、设置与工作区文件

如需将数据迁移到其他位置，可设置环境变量 BLUESPIRIT_HOME 指向目标目录。

5模型服务配置

蓝灵不内置任何 API Key。使用 AI 对话与设计 Agent 时，需要在设置中添加一个 OpenAI 兼容的模型服务商。

配置要点

  • 进入设置 → AI 配置，左侧选择服务商，右侧填写名称、接口地址、API Key 与模型列表。
  • 可添加任意数量的自定义服务商，并将常用模型设为默认。
  • 未配置 API Key 时，界面、镜头设计分析与光场调控等本地计算功能仍可正常使用。

6卸载

提供三种卸载入口，任选其一即可：

  • 开始菜单 BlueSpirit 分组中的「卸载蓝灵」。
  • 运行 %LOCALAPPDATA%\BlueSpirit\Uninstall.exe。
  • Windows 设置 → 应用 → 已安装的应用 → 蓝灵 BlueSpirit → 卸载。
卸载会移除程序文件、快捷方式与独立运行环境，但不会删除 %APPDATA%\BlueSpirit 中的任务、报告与镜头版本数据。如需彻底清理，可手动删除该目录。

7常见问题

安装过程中提示网络错误

安装依赖下载失败时，安装器会自动重试并切换镜像。如果多次尝试仍失败，请检查是否可以访问 python.org、bootstrap.pypa.io、pypi.tuna.tsinghua.edu.cn 与 pypi.org。公司代理或安全软件拦截 HTTPS 也会导致下载中断，此时可在系统设置中放行上述站点后重新运行安装包。

在哪里查看安装日志

日志位于安装目录下的 Setup\install.log，其中记录了每一次下载、每一次镜像切换以及最终的校验结果。若你选择了自定义安装目录，日志同样位于该目录的 Setup 子目录中。

安装中断后如何继续

直接重新运行安装包即可。已下载的 Python 运行时缓存在临时目录的 BlueSpirit-Downloads 中，pip 也会复用本地缓存，重装时通常会明显更快。

安装时被安全软件拦截

安装包包含独立运行时的释放与依赖安装行为，部分安全软件会将其判定为可疑程序。请将安装包加入白名单后重新运行，或从官网重新下载最新版本。

启动时没有反应或闪退

可在命令提示符中运行入口脚本查看真实报错：

"%LOCALAPPDATA%\BlueSpirit\BlueSpirit\runtime\python\python.exe" "%LOCALAPPDATA%\BlueSpirit\BlueSpirit\main.py"

浏览器控制功能无法连接

浏览器控制通过本机调试端口连接已启动的浏览器。若端口被占用，可在设置中调整浏览器端口后重试。
